# Security policy

This project is a bootstrap and has no released production runtime. No supported release series is declared yet.

Report suspected vulnerabilities privately through GitHub's private vulnerability reporting for `Jerry-Xin/x-buddy` if available. Otherwise contact the repository owner privately through their GitHub profile and request a secure reporting channel; do not put vulnerability details or credentials in public issues. Enabling private vulnerability reporting is an owner-managed setting and is not asserted here.

The CI scan checks common credential and private endpoint patterns plus source license headers. It is a bounded automated check, not a comprehensive security audit. All future dependencies and outbound capabilities still require independent review.
